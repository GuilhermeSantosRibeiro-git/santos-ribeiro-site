# Santos Ribeiro Site

Site institucional desenvolvido com Next.js 15, TypeScript e Tailwind CSS para a Santos Ribeiro.

## Divisões

- Santos Ribeiro Engenharia
- Santos Ribeiro Infraestrutura
- Santos Ribeiro Construtora
- Santos Ribeiro Ambiental
- Santos Ribeiro SST

## Páginas

- Home
- Quem Somos
- Engenharia
- Infraestrutura
- Construtora
- Ambiental
- SST
- Portfólio
- Blog
- Contato

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run start
```

O projeto utiliza a arquitetura App Router do Next.js e está pronto para deploy na Vercel.
